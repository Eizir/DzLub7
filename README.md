Алгоритм решения
1.  Начало.
2.  Присвоить переменным конкретные значения (контрольный пример):  x = 0 ,  y = 1 .
3.  Проверить условие  y < 0 .
 •  Если да → вывести «Точка НЕ принадлежит области» → конец.
4.  Проверить условие  x < -2  или  x > 4 .
 •  Если да → вывести «Точка НЕ принадлежит области» → конец.
5.  Если  x \le 0 , проверить  y \le \sqrt{4 - x^2} .
 •  Если да → «Точка принадлежит области».
 •  Если нет → «Точка НЕ принадлежит области».
6.  Если  x > 0 , проверить  y \le 2 - 0{,}5 \cdot x .
 •  Если да → «Точка принадлежит области».
 •  Если нет → «Точка НЕ принадлежит области».
7.  Вывод результата.
8.  Конец.
Контрольный пример:  x = 0 ,  y = 1  — точка лежит внутри (на оси  y  ниже вершины).
